Project Overview

The Fleet Management System is a web-based application developed using Django to simplify and improve the management of an organization's fleet operations. It helps users manage vehicles, staff, assignments, fuelling, repairs and servicing records in one centralized system.

Key Features

- Dashboard: Displays an overview of fleet activities and records.
- Vehicle Management: Register, view and manage vehicle information.
- Staff Management: Manage staff details and contact information.
- Vehicle Assignment: Record and manage vehicle assignments to staff.
- Fuelling Management: Track vehicle fuelling activities and costs.
- Repair Management: Record vehicle repair issues and repair records.
- Service Management: Manage vehicle servicing issues and service records.
- User Authentication: Provides secure login and access to system functionality.

Installation and Setup

1. Clone the repository:
   git clone https://github.com/RayanSsozi3/Fleet-Management-System.git
  

2. Navigate into the project directory:
   cd Fleet-Management-System

3. Create and activate a virtual environment:
   python -m venv .venv

4. Install the required dependencies:
   pip install -r requirements.txt

5. Apply database migrations:
   python manage.py migrate

6. Start the development server:
   python manage.py runserver
